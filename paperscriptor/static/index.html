Write a research paper

Turn your idea and experiment notes into a LaTeX paper. Four agents run in order: outline, literature review, section writing, then review and refinement.

OpenRouter

Your key goes only to this local server and to OpenRouter.

A key in the .env file will be used if this is empty.

Not needed if you use local models only: type ollama/<model> in the model boxes.

Writes the outline, sections and revisions. For a local model, use ollama/<model>.

Suggests papers to cite. A cheap model is fine; Inkling 2 Small knows paper titles well.

Your research

Type or paste your notes, load a file into a box, or add whole documents below. The paper uses only what you provide, so include every number you want in the tables.

Problem, core idea, method details, equations, contributions.

Datasets, baselines, metrics, result tables, ablations, observations.

Documents (optional)

Documents: Markdown, text, PDF, Word, LaTeX, CSV, JSON. Captions are read from any file with "caption" in its name.

    Drafts, notes, proposals, result sheets. Set each one to Idea, Results or Both, so the writer knows where tables must come from. Scanned PDFs without a text layer can't be read.

    Figures (optional)

    PNG, JPG or PDF. Add a caption so the writer knows what each figure shows.

      Settings

      Only papers published up to this month are cited.

      Your template files

      Upload the journal's or conference's LaTeX kit: the main .tex file plus its .cls, .sty and .bst files. Sample text in the template is replaced.

      The most important searches run first. Fewer searches cost less.

      Optional steps stop when this is reached. 0 means no limit.

      Advanced

      Without one, paper checks share a public rate limit and may be slower.

      OpenAlex is the backup paper database. Without a key it allows about 100 checks a day; a free key from openalex.org raises that to about 1,000.

      Progress

      Nothing running yet. Fill in the form and press Write my paper. A full run usually takes 10 to 25 minutes.
